# tekkonaut.github.io

Coming-soon page for Tekkonaut, deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

Plain static files, no build step. Logo, icons and the Open Graph image come from the Tekkonaut CI assets (styleguide 1.8, `documents` repo, `Tekkonaut-CI-Assets/`); the font is Jost (SIL OFL, `fonts/OFL.txt`).

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
